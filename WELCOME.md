# 👋 Welcome to Your Portfolio!

Your production-ready portfolio website is ready to launch.

## ⚡ Get Started in 3 Steps

### 1️⃣ Install & Run (2 minutes)

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) — your site is live! 🎉

### 2️⃣ Update Your Content (5 minutes)

Run this command to find what needs updating:

```bash
npm run find-placeholders
```

Then update:
- Social media links (Dribbble, Behance, LinkedIn, Twitter, Instagram)
- Email address
- Domain name
- Resume PDF
- OG image for social sharing

**See [TODO.md](TODO.md) for complete checklist.**

### 3️⃣ Deploy (5 minutes)

```bash
npm run build
vercel --prod
```
